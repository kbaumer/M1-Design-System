# M1-Design-System
Add Submission record containing the required links, testing evidence, code defense, and AI disclosure.

Repository URL: A working link to the repository with meaningful commits.
Published specimen URL: A working public link to the coded specimen page.
Test record: The required conditions, expected results, observed results, evidence, and revisions.
AI disclosure: A meaningful assistance and verification record, or the statement “No generative AI was used.”
Code defense: A concise explanation of the reset strategy, token hierarchy, one scoped theme override, and one evidence-based revision.
